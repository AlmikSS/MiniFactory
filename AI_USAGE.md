# AI Usage

## Какие инструменты использовались

- **DeepSeek** — консультации, генерация кода, ревью.

## Какие задачи передавались

- Обсуждение архитектурных решений (слои, развязка систем).
- Разбор незнакомых API: Unity IAP v5, архитектура аналитики.
- Написание unit-тестов.
- Генерация шаблонного кода: события, DTO, конфиги.
- Ревью существующего кода, поиск ошибок.

## Что реализовано с помощью AI

- **Тесты** — основная помощь: структура asmdef, `SerializedObject` для приватных полей, шаблоны NUnit-тестов.
- **Аналитика** — архитектура `IAnalyticsProvider` + `AnalyticsService` + listener. Ранее опыта с multi-provider аналитикой не было.
- **IAP** — структура `IPurchaseGateway` и обёртка над Unity IAP v5. API v5 изучал по документации, AI помог со скелетом и обработкой ошибок.
- Шаблонные DTO, события, конфиги.

## Что сделано самостоятельно

- Игровая логика: машины, апгрейды, boost, offline-прогресс.
- Интеграция с тулкитом.
- Сохранения (`SaveService`, JSON в `persistentDataPath`, mobile lifecycle).
- UI и управление.
- Финальные архитектурные решения — выбирал сам.

## Итог

AI использовался как консультант и ускоритель шаблонного кода. Ключевая помощь — в областях, где не было опыта (тесты, аналитика, IAP). Архитектурные решения, игровая логика и интеграция с тулкитом — сделаны самостоятельно.
